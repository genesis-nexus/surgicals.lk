## GitHub Pages Setup

This site is configured to be served via GitHub Pages from the `docs` folder.

### Setup Instructions

1. Ensure all files are in the `docs` folder
2. Enable GitHub Pages in repository settings
3. Set source to "Deploy from a branch"
4. Select "main" branch and "/docs" folder
5. The site will be available at `https://[username].github.io/surgicals.lk`

### Custom Domain

The site is configured for the custom domain `surgicals.lk`:
- CNAME file is included in the docs folder
- DNS should point to the GitHub Pages URL
